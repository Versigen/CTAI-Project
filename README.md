# CTAI-Project


Vogue Thrifts
📌 Overview

Cloud technologies project - Developed a virtual wardrobe website integrating AWS cloud services

⚡ Versions
🔹 Hardcoded Version

Runs immediately with no setup.

Useful for quick testing and reviewing logic.

Data is stored locally.

How to Run:

git clone <repo_url>
cd project-folder
python main.py

🔹 API Version

Connects to a real external API.

Shows ability to work with live data and handle requests.

Requires hosting or an API key to run properly.

How to Run (Locally):

git clone <repo_url>
cd project-folder
pip install -r requirements.txt
# Add your API key to .env file
python app.py


Note: This version may not run fully unless hosted on the cloud. See the screenshots/demo below.
